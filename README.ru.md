# tg-history-agent

[English](README.md) | **Русский**

ИИ-агент, отвечающий на вопросы по истории вашей Telegram-группы — со ссылками на конкретные сообщения. Спросите «что решили по схеме БД?» — он итеративно переберёт всю историю (ключевой FTS-поиск, без эмбеддингов), прочитает контекст вокруг находок, восстановит ветки ответов и ответит ссылками `t.me/c/...`, которые открываются прямо в группе.

Построен на [Claude Agent SDK](https://docs.anthropic.com/en/api/agent-sdk/overview) — работает на вашей подписке Claude через OAuth Claude CLI, API-ключи не нужны.

## Как это работает

```
Telethon (ваш аккаунт) ──► SQLite FTS5-индекс ──► тулы агента ──► Telegram-бот
   бэкфилл + live             сообщения,            12 поисковых     личка
   new/edit/delete            топики, участники     инструментов     + @упоминания в группе
```

1. **Индексатор** — [Telethon](https://github.com/LonamiWebs/Telethon)-клиент под *вашим* личным аккаунтом (вы же состоите в группе) выкачивает всю историю в SQLite с FTS5 и дальше слушает вживую: новые сообщения, правки, удаления, топики форума, реакции, закрепы, имена файлов.
2. **Агент** — Claude-агент, у которого из инструментов только 12 поисковых примитивов над этим индексом. Ищет *итеративно*: несколько вариантов запроса (префиксы FTS5 компенсируют морфологию), grep точных подстрок (коды ошибок, URL), раскрытие находок через контекст и ветки, пики активности — и только потом ответ.
3. **Бот** — обычный Bot API long polling. Личка — по allowlist и/или членству в группе (снимок участников снимается Telethon'ом — боту даже не нужно состоять в группе). В группе отвечает любому по @упоминанию. Стриминг ответов через `sendMessageDraft`.

### Инструменты агента

| Тул | Назначение |
|---|---|
| `search` | полнотекстовый FTS5-поиск: фильтры по топику/автору/датам, пагинация, сортировка |
| `grep` | точная подстрока — коды ошибок, URL, имена функций, части слов |
| `context` | переписка вокруг сообщения (в его топике) |
| `thread` | вся ветка ответов: вверх до корня и вниз по всем ответам |
| `read` | пачка сообщений по ids или диапазону |
| `topics` | топики форума с объёмами |
| `senders` | участники с числом сообщений |
| `activity` | гистограмма по дням/неделям — найти пики обсуждений и копнуть |
| `pinned` | закреплённые сообщения |
| `files` | документы по имени файла или подписи |
| `top_reacted` | сообщения с наибольшим числом реакций |
| `stats` | обзор индекса |

Каждая находка приходит с готовой ссылкой `https://t.me/c/...` (с учётом топиков форума), работающей у любого участника группы.

## Установка

Нужны: [uv](https://github.com/astral-sh/uv), авторизованный [Claude CLI](https://docs.anthropic.com/en/docs/claude-code) (подписка), Telegram-аккаунт, состоящий в целевой группе.

```bash
cp .env.example .env
# 1. TG_API_ID / TG_API_HASH — на https://my.telegram.org → API development tools
uv sync

# 2. Одноразовый вход своим аккаунтом (двухшаговый, без интерактивного stdin):
uv run python -m app.login +79991234567          # отправит код
uv run python -m app.login +79991234567 12345    # вход (пароль 2FA — третьим аргументом)

# 3. Выбрать id группы, вписать в TG_TARGET_CHAT:
uv run python -m app.chats

# 4. TG_BOT_TOKEN — создать бота у @BotFather
uv run python -m app.main                        # стартует бэкфилл и бот
```

`uv run python -m app.profile` — сводка индекса (объём, топики, авторы, медиа).

## Деплой (Docker)

```bash
docker compose up -d --build
```

Compose монтирует `./data` (индекс + сессии) и ваш `~/.claude` (OAuth-креды Claude CLI; рефреш токена пишется туда же). Логин Telethon можно сделать на любой машине и привезти `data/user.session` вместе с проектом — бэкфилл продолжится с места остановки.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_API_ID` / `TG_API_HASH` | — | ключи приложения с my.telegram.org |
| `TG_TARGET_CHAT` | — | индексируемая группа: `-100…` id или `@username` |
| `TG_BOT_TOKEN` | — | токен бота; пусто — бот выключен (индексатор работает) |
| `TG_ALLOWED_IDS` | — | доступ к личке: id через запятую и/или слово `group` (любой участник группы) |
| `CLAUDE_MODEL` | `sonnet` | модель агента |
| `SESSION_FRESH_HOURS` | `6` | простой, после которого чат получает свежую сессию агента |

## Ограничения

- Одна группа на инстанс (схема БД готова к нескольким, конфиг — нет).
- Только ключевой поиск — эмбеддингов нет намеренно; итеративность агента закрывает большую часть «семантического» разрыва.
- Содержимое медиа не индексируется (подписи фото и имена файлов — да).
- Стриминг черновиком требует клиентов с Bot API 9.5+; иначе тихий фолбэк на «печатает…».
- Промпты агента на русском — для других языков правьте `app/agent.py`.
